# 힐링 오하나 훌라

10주간의 배움과 연습을 담은 동아리 아카이브입니다.

## 구성
- 주차별 기록: 1~10주차 사진·영상 37개
- 연습곡별: Ke Aloha, Pearly Shell, Ke Ao Nani, Hawaiian Wedding Song의 강사·연습 영상 및 기본 스텝 영상 19개. 사진은 제외합니다.
- 강남라이프: 파일명에 강남라이프가 포함된 사진 31개, 촬영 출처 표시
- 종강 기념 영상: 「강남 힐링 훌라 오하나 · 10주의 기록」
- 워크숍 사진 4개는 별도 접힌 영역에 표시합니다.

## 운영
빌드 도구나 외부 서비스 없이 HTML/CSS/JavaScript로 작동합니다. GitHub Pages의 main 브랜치 루트에서 배포합니다. 모든 웹 파일과 미디어는 같은 폴더에 있습니다.

새 기록을 추가할 때 사진 또는 MP4와 썸네일을 올리고 media.json의 items에 항목을 추가합니다. 각 항목은 id, src, thumb, type(image/video), week(1~10 또는 null), song, category, title, original, duration(초)으로 구성됩니다. 파일 경로는 같은 폴더의 파일명만 사용합니다.

곡 키: ke-aloha / pearly-shells / ke-ao-nani / hawaiian-wedding / basic. 분류: instructor / practice / attendance / photo / press / workshop / mv.

로컬에서는 정적 웹 서버로 열어야 합니다. file:// 직접 실행은 브라우저의 JSON 읽기 제한을 받을 수 있습니다.

## 자료 기준
커리큘럼 이미지 파일은 확인되지 않아 참가신청서의 회차별 세부 학습계획을 참고했습니다. 계획과 실제 파일의 후반부 날짜가 달라 주차 구분은 실제 파일명을 따릅니다. 내부 문서와 별도 음원은 게시하지 않았습니다.

곡명이 없는 수업 영상 2개는 영상 자막으로, 연습 영상 3개는 제공된 음원과 두 구간의 오디오 지문을 대조해 Ke Aloha로 확인했습니다.

사진·영상은 원본과 별도로 웹용 사본을 생성했습니다. 잘못된 확장자는 실제 형식에 맞춰 바로잡았고, 동영상은 브라우저 호환 H.264/AAC MP4와 빠른 시작 방식으로 저장했습니다. 원본 폴더는 수정하지 않았습니다.

## 이용 및 권리
동영상은 자동 재생되지 않습니다. 사진 확대, 영상 재생, 이전·다음, 검색과 필터, 모바일 화면 및 키보드 탐색을 지원합니다.

강남라이프 사진의 촬영 출처는 강남라이프입니다. 사진·영상의 권리는 각 권리자에게 있으며 공개 저장소에 포함되었다는 사실이 재사용 허락을 뜻하지는 않습니다.
