# 힐링 오하나 훌라

크림, 파인 그린, 코랄 컬러의 한국어 반응형 정적 아카이브입니다. 빌드 도구, 외부 폰트, CDN, 외부 API가 필요하지 않습니다.

## 이 작업에서 작성한 파일

- `index.html`: 히어로, 종강 기념 영상, 아카이브, 네이티브 미디어 다이얼로그
- `styles.css`: 데스크톱·태블릿·모바일 레이아웃, 포커스, 모션 감소 설정
- `app.js`: JSON 로딩, 필터, 검색, 커리큘럼, 워크숍, 미디어 뷰어
- `README.md`: 실행 및 데이터 안내

미디어 파일 및 media.json은 이 작업에서 만들거나 수정하지 않았습니다. 같은 디렉터리에 별도로 공급해야 합니다.

## 실행 / 배포

1. 네 파일과 media.json, 모든 미디어를 같은 디렉터리에 둡니다.
2. 로컬에서는 정적 웹 서버를 통해 접속합니다. file://로 직접 열면 브라우저의 fetch 보안 제한으로 JSON을 읽지 못할 수 있습니다.
3. GitHub Pages에서는 해당 디렉터리 내용이 배포 루트가 되도록 설정합니다. 모든 리소스 주소가 ./로 시작하므로 프로젝트 하위 경로에서도 동작합니다.
4. 처음 로드할 때 JSON과 이미지 위주로 로딩하며 동영상은 재생 전에 내려받지 않습니다. 동영상 자동재생은 사용하지 않습니다.

## 필수 로컬 파일

- `media.json`
- `press-21.jpg`: 메인 히어로의 실제 모임 사진
- `mv-poster.jpg`: 종강 기념 영상 포스터
- `mv.mp4`: 종강 기념 영상 (JSON의 category: mv 항목이 있으면 해당 항목 우선)
- JSON의 각 src / thumb 파일

모든 src / thumb는 같은 디렉터리의 평면 파일명이어야 합니다. 하위 디렉터리, 외부 URL은 사용하지 않습니다. 한글, 공백, 괄호를 포함한 파일명은 앱에서 URL 인코딩합니다. 썸네일이 없거나 로딩에 실패해도 기본 아이콘과 제목으로 카드를 표시합니다.

## 데이터 계약

```json
{
  "items": [
    {
      "id": "unique-id",
      "src": "flat-video.mp4",
      "thumb": "flat-video.jpg",
      "type": "video",
      "week": 1,
      "song": "unassigned",
      "category": "practice",
      "title": "파일에서 확인한 제목",
      "original": "원본 파일명.mp4",
      "duration": 82
    }
  ],
  "curriculum": [
    {
      "week": 1,
      "songs": ["ke-aloha"],
      "note": "확인된 학습계획 내용",
      "source": "참가신청서의 학습계획"
    }
  ]
}
```

위 객체는 구조를 설명하기 위한 예시이며 실제 데이터로 생성되지 않습니다.

- type: image 또는 video
- week: 1~10의 정수 또는 null
- song: ke-aloha / pearly-shells / ke-ao-nani / hawaiian-wedding / basic / unassigned / null
- category: instructor / practice / attendance / photo / press / workshop / mv
- duration: 초 단위 숫자. 알 수 없으면 0 또는 null; 임의의 길이를 표시하지 않습니다.
- curriculum은 선택 사항입니다. songs에는 곡 키 또는 확인된 곡명 문자열을 넣을 수 있습니다.
- JSON의 텍스트는 HTML로 해석하지 않고 텍스트로 표시합니다.

## 아카이브 동작

- **주차별**: 전체 및 1~10주차 버튼. 주차가 있는 사진·영상을 모두 표시합니다. 강남라이프, 워크숍, 종강 영상은 별도 영역에 둡니다.
- **연습곡별**: 일반 기록 중 영상만 표시합니다. Ke Aloha → Pearly Shells → Ke Ao Nani → Hawaiian Wedding Song 순서로 네 곡을 제공합니다. 기본 동작, 곡 미분류는 해당 영상이 실제 존재할 때만 추가합니다. song이 null이거나 알 수 없으면 곡 미분류로 처리합니다.
- **강남라이프**: 원본명 또는 src에 강남라이프가 있거나 category가 press인 기록을 빠짐없이 표시하고 강남라이프 촬영 크레딧을 붙입니다. 수량은 JSON에서 계산합니다.
- 강사 영상 / 연습 영상 필터는 선택된 주차·곡에 해당 category의 영상이 실제 있을 때만 보입니다. 전체 기록을 선택하면 사진도 다시 포함됩니다.
- 검색은 현재 모드와 필터 안에서 제목, 원본명, 주차, 곡, 분류를 찾습니다. 검색 결과 없음, 빈 데이터, JSON 로딩 실패는 서로 구분하여 안내합니다.
- 커리큘럼이 있으면 접힌 학습계획과 선택 주차별 내용을 표시합니다. 실제 촬영 날짜를 계획 날짜로 추정하지 않습니다. 다음 안내를 함께 제공합니다: **학습 내용은 참가신청서의 계획을 참고했으며, 실제 기록은 파일의 주차 구분을 따릅니다.**
- workshop 이미지가 있으면 별도의 접힌 워크숍 영역에 표시합니다.
- 데이터의 제목이 없으면 알려진 주차에 대해 N주차의 기록으로 표시합니다. 확인되지 않은 날짜나 행사를 만들어내지 않습니다.

## 뷰어 / 접근성

- 네이티브 dialog를 사용하며 열 때 닫기 버튼으로 포커스를 이동합니다.
- Escape / 닫기 / 바깥 배경 클릭으로 닫습니다. 닫거나 이전·다음 기록으로 이동할 때 동영상을 멈추고 재생 상태를 초기화합니다. 닫으면 원래 카드로 포커스를 돌립니다.
- 이전·다음 버튼과 좌우 방향키로 현재 필터의 기록을 순환합니다. 동영상 컨트롤에 포커스가 있으면 방향키를 가로채지 않습니다.
- 동영상 controls / playsinline / preload=none, 사진 object-fit: contain을 사용합니다. 사용자가 뷰어를 연 뒤 동영상의 재생 버튼을 눌러 재생합니다.
- 탭 목록의 좌우 방향키 / Home / End, 검색 레이블, 결과 상태 안내, skip link, 가시적 키보드 포커스, 44px 이상 주요 터치 영역을 제공합니다.
- prefers-reduced-motion 설정 시 부드러운 이동과 전환 효과를 줄입니다.
- 상단의 주차별 기록·연습곡·강남라이프 링크는 실제 모드를 전환하고 해당 영역으로 이동합니다. #weeks / #songs / #press 직접 링크도 지원합니다. #mv는 영상 영역으로 이동합니다.

## 배포 전 확인

1. media.json 요청이 200이고 JSON 구조가 일치하는지 확인합니다.
2. 강남라이프 데이터 31개, 전체 주차별 기록 수, 연습곡별 영상 수가 원본 목록과 맞는지 확인합니다. 개수는 하드코딩하지 않았습니다.
3. 히어로 크롭 및 각 썸네일이 실제 인물을 적절히 담는지 확인합니다.
4. 모바일에서 필터, 검색, 종강 영상, 이미지 확대와 이전·다음, Escape 닫기를 확인합니다.
5. MP4가 브라우저 호환 코덱인지, 영상 길이가 JSON과 일치하는지 확인합니다.
6. 외부 폰트나 네트워크 의존성이 없는지, GitHub 프로젝트 경로에서 모든 파일이 열리는지 확인합니다.

## 자료 확인 사항

- 주차별 기록 37개, 강남라이프 사진 31개, 워크숍 사진 4개, 종강 기념 영상 1개를 포함합니다.
- 이름에 강남라이프가 있는 사진 31개는 강남라이프 촬영 섹션에 배치했습니다.
- 커리큘럼 이미지 파일은 확인되지 않아 참가신청서의 회차별 세부 학습계획을 참고했습니다. 후반부 계획 날짜와 실제 파일명이 다르므로 주차 구분은 파일명을 따릅니다.
- 파일명에 곡명이 없는 수업 영상 2개는 자막으로, 연습 영상 3개는 첨부 음원과 서로 떨어진 두 구간의 오디오 지문을 대조하여 Ke Aloha로 확인했습니다.
- 원본 내부 문서, 참가자 개인정보 및 별도 음원 파일은 업로드하지 않습니다.
- 사진·영상의 권리는 각 권리자에게 있습니다. 공개 저장소에 포함되어 있다는 사실이 재사용 허락을 의미하지 않습니다.
